Getting Started

Organising topics

A topic is a folder. A subtopic is a numbered folder inside it. A page is one HTML file.

Key ideas

  • Topic. One subject, such as an exam you are studying for.
  • Subtopic. A numbered folder like "01 Basics", which keeps things in order.
  • Page. One concept per page. Many short pages beat one long one.
  • Tags. Add tags to a page to find related pages across topics.
Common trapLong pages are hard to link to. If a page covers two ideas, split it.

Check yourself

Why number subtopic folders?

Answer: The number sets the order in the sidebar, so a topic reads from start to finish.
